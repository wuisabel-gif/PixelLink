# PixelLink ESP32 + CC1101 firmware

Start with `../docs/hardware.md` for the **3.3 V-only wiring**, matched antennas,
authorization requirements, build/flash instructions, and serial commands.
The exact 28-byte payload and USB JSON contract are in `../docs/protocol.md`.

```sh
# From this directory: build only, no flash or transmission
pio run -e transmitter -e receiver
python3 test/run_native.py
```

A virgin device has no frequency and cannot transmit. Explicit `FREQ <MHz>`
configures the radio; transmitter `TX ARM` grants only a 60-second lease, with
at most one real uptime/optional ADC packet attempt each second. RX never
transmits. `SAVE` explicitly persists frequency and node ID for reconnects;
ARM and ADC are never restored. `CLEAR` removes saved settings. No simulated
images or sensor measurements are generated by this firmware.

Build configuration pins Espressif32 6.12.0 and RadioLib 7.7.1. Native codec
tests consume the repository's independent `tests/fixtures/telemetry_vectors.json`.
No physical validation, flashing, or RF transmission was performed during
implementation.
