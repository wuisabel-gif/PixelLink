Connect your receiver

  1. Install hardware support: pip install ".[hardware]"
  2. Find the receiver: python -m pixellink ports
  3. Configure the firmware frequency explicitly in a serial monitor. Use SAVE if you want the configured frequency/node to survive a USB-open reset, then close the monitor. Transmitter arming is never restored.
  4. Start: python -m pixellink serve --serial-port /path/to/receiver

The host never sends configuration or TX ARM commands. DTR/RTS are deasserted before opening; USB drivers may still reset an ESP32. If status is unconfigured, close the host and configure again. This page never falls back to simulation.
